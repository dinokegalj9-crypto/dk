Layout

The frame is part of the image. Asymmetry over the centered grid — memory is off-balance.

.frame · .offset-left — content settles off-center

.prose--narrow holds an intimate reading column at 44ch, so the words sit in a pool of quiet rather than stretching the full width of the screen.
