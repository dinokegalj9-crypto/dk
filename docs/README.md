# Sensorium — Documentation

> Sensorium is not a perfume brand. It is an instrument for re-entering states you thought you had lost.
> Scent is the trigger. Memory is the product.

This directory is the **constitution** of Sensorium. Every design, word, image, motion, and
material decision should be traceable back to one of these documents. When something feels
wrong, the answer is here. When two ideas conflict, the document closest to the *soul* wins —
and the soul is defined first, in the Brand Guidelines.

## How to read these

- **Principles, not rules.** Each document leads with *why*, then *how*. If a rule stops
  serving the feeling, the principle overrules the rule.
- **Restraint is the luxury.** Across all eight documents, the recurring instruction is the
  same: withhold, slow down, leave silence. Intensity is earned, never default.
- **The interface should feel like remembering, not browsing.** This single sentence is the
  test. Apply it to any decision.

## The one test

Before shipping anything, ask:

> *Does this make a person feel like they are remembering something — or like they are using a website?*

If it's the latter, it isn't finished.
